# BigMart Sales Prediction using Machine Learning

This project focuses on predicting product sales for BigMart outlets using Machine Learning algorithms. The dataset is preprocessed by handling missing values, encoding categorical variables, and scaling features before training the model.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## ML Techniques Used
- Data Preprocessing
- Label Encoding
- Feature Scaling
- Random Forest Regression

## Features
- Handles missing values
- Cleans inconsistent categorical data
- Trains and evaluates ML model
- Generates predictions on test dataset
- Displays feature importance
- Visualizes actual vs predicted sales

## Output
The project generates a CSV file containing predicted sales values for the test dataset.
